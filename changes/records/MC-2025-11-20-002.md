## Overview

The user wanted a single command that could run the freeze-ready release pipeline, refresh the goals log, log a Master Change, and dry-run the rebrand playbook without jumping between CLIs. This master change delivers that experience through `scripts/workflow_harness.py`, a Control Center wrapper, and an Ops Deck command entry so every guardrail fires in one pass.
