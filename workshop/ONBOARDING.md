# Workshop Onboarding Guide

Welcome to the Workshop Relay! This guide will help you get started:

## What is Workshop?
- Workshop is a modular notebook system for building, chaining, and sharing Recipes (notebook pages) and Cookbooks (collections).

## Getting Started
1. Explore example notebooks in `workshop/notebooks/`.
2. Open `welcome_cookbook.ipynb` for a guided tour.
3. Try running cells and chaining outputs.
4. Create your own Recipe by adding a new notebook.

## Extending Workshop
- Add new Recipes: Create a notebook in `workshop/notebooks/`.
- Build Cookbooks: Group related Recipes together.
- Use extension templates in `workshop/widgets/` and `workshop/scripts/`.
